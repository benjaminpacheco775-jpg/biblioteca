Laboratorio de Mantenimiento de Software

El mantenimiento de software comprende las actividades destinadas a conservar los programas informáticos en condiciones correctas de funcionamiento, resolver problemas y mejorar su rendimiento y seguridad.

Unidad N.º 1: Evolución de los ambientes de software

1. ¿Qué es un ambiente de software?

Es el conjunto de sistemas operativos, programas, bibliotecas, herramientas y recursos necesarios para ejecutar una aplicación. Su organización fue evolucionando junto con el desarrollo de las computadoras y las redes.

2. Operación centralizada

En un ambiente centralizado, el procesamiento principal se realiza en una computadora central. Los usuarios acceden a sus recursos desde terminales u otros dispositivos conectados.

  • Monousuario: diseñado para que un usuario utilice el sistema a la vez.
  • Multiusuario: permite que varios usuarios accedan al mismo sistema, incluso simultáneamente.

3. Operación distribuida

El procesamiento y los recursos se distribuyen entre varias computadoras conectadas mediante una red. Cada equipo puede realizar tareas y compartir información con los demás.

4. Multiprocesamiento

Consiste en utilizar dos o más procesadores o núcleos para ejecutar tareas de forma concurrente, aumentando la capacidad de procesamiento cuando el sistema y las aplicaciones lo permiten.

Ambiente Característica Ejemplo
Centralizado Recursos concentrados en un equipo central. Sistema de terminales de una empresa.
Distribuido Varios equipos cooperan mediante una red. Aplicación con servidor y clientes.
Multiprocesamiento Uso de varios procesadores o núcleos. Servidor con múltiples núcleos.

5. Instalación de software con poca documentación

Algunos programas poseen documentación escasa o poco clara. Antes de instalarlos es necesario identificar su procedencia, versión, requisitos y compatibilidad con el sistema operativo.

  • Comprobar los requisitos mínimos y recomendados.
  • Verificar la arquitectura compatible: 32 o 64 bits.
  • Revisar dependencias, bibliotecas y controladores necesarios.
  • Analizar la reputación del desarrollador y el origen del instalador.
  • Crear una copia de seguridad o utilizar un entorno de prueba.
  • Evaluar posibles riesgos para los datos y la seguridad.
Importante: no se debe instalar software desconocido directamente en un equipo de producción sin evaluar sus riesgos.

Unidad N.º 2: Diagnóstico de problemas de software

1. ¿Qué es el diagnóstico?

Es el proceso de identificar la causa de un problema informático mediante observaciones, pruebas y análisis de los resultados. Un diagnóstico correcto evita aplicar soluciones innecesarias.

2. Criterios de ensayo y descarte

Consisten en realizar pruebas ordenadas para confirmar o descartar posibles causas de una falla.

  1. Identificar el síntoma y cuándo aparece.
  2. Recopilar mensajes de error y antecedentes.
  3. Revisar cambios recientes en el sistema.
  4. Probar una posible causa por vez.
  5. Registrar los resultados y descartar hipótesis.
  6. Aplicar la solución y comprobar su funcionamiento.

3. Problemas frecuentes

  • Aplicaciones que se cierran inesperadamente.
  • Errores de compatibilidad.
  • Falta de memoria o espacio de almacenamiento.
  • Controladores incorrectos o desactualizados.
  • Archivos del sistema dañados.
  • Infecciones por software malicioso.
  • Problemas de conexión con servidores o bases de datos.

4. Estrategias de resolución

La solución puede consistir en actualizar un programa, reparar archivos, modificar una configuración, reinstalar un componente o restaurar una copia de seguridad.

5. Economía de la solución

Se deben comparar el tiempo, el costo, los riesgos y los beneficios de cada alternativa. Una solución económica no es necesariamente la de menor precio inicial, sino la que resuelve el problema de manera confiable con un costo total razonable.

6. Tendencias en ambientes de software

  • Sistemas operativos: Windows, distribuciones GNU/Linux y otros sistemas especializados.
  • Bases de datos: MySQL, PostgreSQL, SQL Server y otros gestores.
  • Virtualización: ejecución de sistemas virtuales sobre un equipo físico.
  • Contenedores: empaquetado de aplicaciones y dependencias en entornos aislados.
  • Computación en la nube: utilización de recursos informáticos a través de Internet.

Unidad N.º 3: Mantenimiento, actualización y optimización

1. Tipos de mantenimiento

Preventivo

Busca reducir la probabilidad de fallas mediante actualizaciones, revisiones, copias de seguridad y controles periódicos.

Correctivo

Se realiza después de detectar una falla para reparar el problema y recuperar el funcionamiento normal.

2. Actualización de sistemas y aplicaciones

Actualizar significa instalar una versión más reciente o aplicar mejoras de seguridad y funcionamiento. Antes de hacerlo se deben verificar la compatibilidad, los requisitos y las posibilidades de recuperación.

  • Actualizar el sistema operativo.
  • Instalar controladores compatibles.
  • Actualizar navegadores y aplicaciones.
  • Revisar licencias y dependencias.
  • Reiniciar cuando sea necesario y comprobar los resultados.

3. Instalación, configuración y desinstalación

La instalación incorpora un programa al equipo. La configuración adapta sus opciones a las necesidades del usuario. La desinstalación elimina el programa mediante un procedimiento controlado, evitando borrar archivos compartidos necesarios para otras aplicaciones.

4. Seguridad informática

La seguridad informática protege los sistemas y los datos contra accesos no autorizados, alteraciones, pérdidas y programas maliciosos.

  • Virus: código malicioso que puede infectar archivos.
  • Gusanos: programas que pueden propagarse entre sistemas.
  • Troyanos: programas que ocultan funciones maliciosas.
  • Ransomware: software que puede bloquear o cifrar información para exigir un rescate.
  • Spyware: software que recopila información sin autorización adecuada.

5. Copias de seguridad y recuperación

Una copia de seguridad es una copia de los datos que permite recuperarlos ante una pérdida, un error o un incidente de seguridad.

  • Completa: copia todos los datos seleccionados.
  • Incremental: guarda los cambios desde la última copia de seguridad realizada.
  • Diferencial: guarda los cambios desde la última copia completa.

La recuperación consiste en restaurar los archivos o el sistema utilizando las copias disponibles. Es fundamental probar que las copias se puedan restaurar correctamente.

6. Optimización del rendimiento

  • Desinstalar programas que ya no se necesitan.
  • Eliminar archivos temporales innecesarios.
  • Controlar las aplicaciones que se inician con el sistema.
  • Revisar el consumo de CPU, memoria RAM y almacenamiento.
  • Comprobar el estado del disco y los registros de errores.
  • Evitar desactivar servicios esenciales sin conocer su función.

Sistemas Operativos en Red

Un sistema operativo en red permite administrar usuarios, archivos, dispositivos, permisos y servicios compartidos entre computadoras. Se utiliza en empresas, instituciones educativas y centros de datos.

Unidad N.º 1: Instalación de la red

1. Preparación de la instalación

Antes de instalar un servidor es necesario determinar su función, los recursos necesarios, la topología de red, el direccionamiento IP, los requisitos de seguridad y las necesidades de almacenamiento.

2. Instalación de nuevos servidores

Un servidor es un equipo físico o virtual que proporciona servicios a otros dispositivos. Puede ofrecer archivos, autenticación, páginas web, bases de datos y asignación de direcciones IP.

3. Carga del sistema operativo de red

  1. Verificar el hardware y los requisitos del sistema operativo.
  2. Preparar el medio de instalación.
  3. Configurar el arranque del equipo.
  4. Instalar el sistema operativo.
  5. Configurar el nombre del servidor.
  6. Asignar la configuración de red correspondiente.
  7. Instalar controladores y actualizaciones.
  8. Comprobar la conectividad y el funcionamiento.

4. Discos y particiones

Una partición es una división lógica de un dispositivo de almacenamiento. Permite organizar el espacio para el sistema operativo, los datos y otras funciones.

5. Duplicación de discos y canales

La duplicación de discos puede mantener copias de los datos para aumentar la disponibilidad. RAID 1, por ejemplo, utiliza discos espejados. La redundancia de canales o enlaces busca mantener la conectividad si falla una ruta, siempre que la infraestructura esté diseñada para ello.

6. Controladores de red

Son programas que permiten al sistema operativo comunicarse con el hardware de red, como las placas Ethernet o los adaptadores Wi-Fi.

Unidad N.º 2: Actualización e instalación de estaciones

1. Proceso de actualización

Antes de actualizar un servidor se deben revisar las versiones instaladas, la compatibilidad, el espacio disponible, las dependencias y las opciones de recuperación.

  • Actualización local: se realiza directamente sobre el servidor.
  • Actualización remota: se administra desde otro equipo a través de la red.

Las actualizaciones remotas requieren una conexión confiable, permisos adecuados y medidas para evitar perder el acceso al servidor.

2. Opciones de instalación

Una instalación nueva configura el sistema desde cero. Una actualización conserva, cuando es compatible, parte de la configuración y los datos existentes. La elección depende de los requisitos y de la situación del sistema.

3. Instalación de estaciones de trabajo

Las estaciones de trabajo son los equipos utilizados por los usuarios para acceder a los recursos de la red. Deben configurarse con un sistema operativo compatible, controladores, aplicaciones y las políticas de seguridad correspondientes.

4. Estaciones sin discos

Son equipos que dependen de un servidor para iniciar el sistema o acceder a su entorno de trabajo. Pueden utilizar arranque por red mediante tecnologías como PXE, junto con los servicios necesarios.

5. Interconexión de redes

La interconexión permite comunicar redes diferentes mediante dispositivos como routers y switches de capa 3. La configuración debe contemplar direcciones IP, rutas y reglas de seguridad.

6. Configuración TCP/IP

TCP/IP es el conjunto de protocolos utilizado para comunicar dispositivos en redes IP.

  • Dirección IP: identifica una interfaz en una red.
  • Máscara o prefijo: determina la porción de red de una dirección IP.
  • Puerta de enlace: permite enviar tráfico a otras redes.
  • DNS: traduce nombres de dominio en información de direccionamiento.
  • DHCP: asigna automáticamente la configuración IP a los clientes.

Unidad N.º 3: Sistema de archivos y seguridad

1. Sistema de archivos

Es el método que utiliza un sistema operativo para organizar, almacenar y recuperar archivos y directorios.

Sistema Característica general
NTFS Común en Windows; admite permisos y otras funciones de administración.
ext4 Muy utilizado en sistemas GNU/Linux.
FAT32 Amplia compatibilidad, con un límite de 4 GB por archivo.
exFAT Diseñado para almacenamiento extraíble y archivos grandes.

2. Organización de directorios

Los directorios permiten agrupar archivos y establecer una estructura ordenada. En una red se pueden crear carpetas compartidas por departamento, proyecto o grupo de usuarios.

3. Secuencias de conexión

Durante el inicio de sesión, el sistema identifica al usuario, verifica sus credenciales, aplica las políticas correspondientes y habilita los recursos que tiene autorizados.

4. Jerarquía de usuarios y privilegios

Los privilegios determinan las operaciones que puede realizar cada usuario. La administración debe asignar solamente los permisos necesarios para cumplir las tareas de cada persona.

  • Administrador: administra el sistema y sus configuraciones autorizadas.
  • Usuario estándar: utiliza aplicaciones y recursos con permisos limitados.
  • Grupo: reúne usuarios para facilitar la asignación de permisos.

5. Derechos de acceso

Los derechos pueden permitir leer, escribir, modificar, ejecutar o eliminar archivos. En una carpeta compartida es importante coordinar los permisos de red con los permisos del sistema de archivos.

Principio de mínimo privilegio: cada usuario debe disponer solamente de los permisos que necesita para trabajar.

6. Tareas de administración

  • Crear y desactivar cuentas de usuarios.
  • Revisar permisos y políticas de seguridad.
  • Supervisar registros de acceso.
  • Controlar copias de seguridad.
  • Documentar cambios y configuraciones.

Unidad N.º 4: Rendimiento y recursos del servidor

1. Utilización del procesador

La utilización de CPU indica cuánto tiempo de procesamiento está ocupado. Un uso elevado y sostenido puede indicar una carga intensa, un proceso defectuoso o una demanda mayor que la capacidad disponible.

2. Estadísticas de memoria

Permiten observar la RAM utilizada, la disponible, la memoria en caché y el uso de memoria virtual. La falta de memoria puede provocar lentitud o errores en las aplicaciones.

3. Planificación de procesos

El sistema operativo distribuye el tiempo de CPU entre los procesos. La prioridad, la cantidad de tareas y las políticas de planificación influyen en el rendimiento general.

4. Estadísticas de recursos

  • Uso del procesador.
  • Consumo de memoria RAM.
  • Espacio libre y actividad de los discos.
  • Tráfico de red y errores de conexión.
  • Procesos y servicios en ejecución.

5. Herramientas de supervisión

Las herramientas dependen del sistema operativo. En Windows pueden utilizarse el Administrador de tareas, el Monitor de recursos y el Visor de eventos. En Linux existen herramientas como top, free, df y herramientas de registro del sistema.

6. Mejoras de rendimiento

Para optimizar un servidor se deben identificar los cuellos de botella, reducir procesos innecesarios, revisar el almacenamiento, comprobar los servicios y ajustar los recursos según la carga real.

Unidad N.º 5: Volúmenes, reparación y servicios

1. Montaje y desmontaje de volúmenes

Un volumen es una unidad lógica de almacenamiento. Montarlo significa hacerlo accesible al sistema operativo. Desmontarlo de forma segura permite cerrar el acceso antes de retirarlo o realizar determinadas tareas de mantenimiento.

2. Reparación de servidores

El procedimiento incluye identificar la falla, evaluar su impacto, proteger los datos, diagnosticar el origen, aplicar una solución y verificar el servicio. Las reparaciones deben documentarse.

3. Principales servicios de red

Servicio Función Puerto habitual
DNS Resuelve nombres de dominio. 53 TCP/UDP
DHCP Asigna automáticamente parámetros IP. 67/68 UDP
HTTP Transfiere contenido web sin cifrado. 80 TCP
HTTPS Comunicación web protegida mediante TLS. 443 TCP
FTP Transfiere archivos; requiere protección adicional cuando se utiliza sin cifrado. 21 TCP para control
SMTP Envía o retransmite correo electrónico. 25, 587 o 465 TCP
IMAP Permite acceder y sincronizar mensajes del servidor. 143 o 993 TCP

4. Implementación de servicios

  1. Definir los objetivos y requisitos.
  2. Instalar el software del servicio.
  3. Configurar parámetros, usuarios y permisos.
  4. Aplicar medidas de seguridad.
  5. Realizar pruebas de funcionamiento.
  6. Ejecutar una prueba piloto.
  7. Corregir errores y documentar la configuración final.

5. Cableado y verificación

El cableado de una red debe instalarse de acuerdo con el diseño, las normas aplicables y las condiciones del lugar. Se pueden usar probadores de continuidad, verificadores de mapa de cableado y certificadores para comprobar diferentes parámetros del enlace.

Redes III

Redes III estudia el diseño, montaje, mantenimiento y administración de infraestructuras de comunicación. Incluye cableado estructurado, fibra óptica, puesta a tierra, mediciones y certificación.

Unidad N.º 1: Mantenimiento y gestión de red

1. Mantenimiento de redes informáticas

Es el conjunto de tareas destinadas a conservar la red operativa, segura y confiable.

  • Preventivo: inspecciones, limpieza, mediciones y revisiones programadas.
  • Correctivo: reparación de fallas ya detectadas.
  • Predictivo: utiliza mediciones y tendencias para anticipar problemas.

La documentación debe registrar los equipos, las conexiones, los resultados de pruebas, las modificaciones y las incidencias.

2. Cableado estructurado

Es un sistema organizado de cables, conectores, paneles y canalizaciones que permite transportar datos dentro de un edificio de forma ordenada y normalizada.

Cableado horizontal

Conecta el distribuidor de planta con las tomas de telecomunicaciones de los espacios de trabajo.

Cableado vertical o backbone

Interconecta plantas, salas de equipos y distribuidores principales del edificio.

3. Normas y estándares

Norma Área principal
ANSI/TIA-568 Cableado estructurado y componentes de telecomunicaciones.
ANSI/TIA-569 Canalizaciones y espacios para telecomunicaciones.
ANSI/TIA-606 Administración, identificación y rotulación.
ANSI/TIA-607 Unión equipotencial y puesta a tierra de telecomunicaciones.
ANSI/TIA-942 Infraestructura de centros de datos.

Las revisiones de estos estándares pueden cambiar con el tiempo. Para un proyecto real se debe consultar la edición vigente y la normativa local aplicable.

4. Tipos de cable de cobre

  • UTP: par trenzado sin blindaje individual o general.
  • STP: denominación utilizada para cables de par trenzado con blindaje.
  • FTP: cable con pantalla general alrededor de los pares.
  • PiMF: pares individualmente rodeados por una lámina metálica.

Los términos de blindaje pueden variar entre fabricantes y especificaciones. Es importante comprobar la construcción real del cable y la forma correcta de instalarlo.

5. Categorías de cable UTP

Categoría Características generales
Cat 5e Admite Gigabit Ethernet hasta 100 metros en un enlace de canal correctamente instalado y certificado.
Cat 6 Mejora el desempeño frente a Cat 5e. Puede admitir 10 Gb/s en distancias reducidas, según las condiciones.
Cat 6A Diseñada para soportar 10 Gb/s hasta 100 metros en un canal conforme a especificaciones.

6. Conectores y terminaciones

  • Plug: conector macho colocado habitualmente en el extremo de un latiguillo.
  • Jack: conector hembra utilizado en tomas de telecomunicaciones.
  • Patchera o patch panel: panel donde terminan y se organizan los cables de una instalación.

7. Secuencia T568B

El estándar T568B establece el orden de los conductores en la terminación de un cable de par trenzado.

  1. Blanco/naranja
  2. Naranja
  3. Blanco/verde
  4. Azul
  5. Blanco/azul
  6. Verde
  7. Blanco/marrón
  8. Marrón
Recordá: un cable directo utiliza el mismo esquema en ambos extremos. Para enlaces modernos, los equipos suelen admitir la detección automática MDI-X.

8. Fibra óptica

La fibra óptica transmite información mediante pulsos de luz. Se utiliza en enlaces de alta capacidad y en distancias donde el cobre presenta mayores limitaciones.

  • Monomodo: núcleo pequeño, utilizado habitualmente en enlaces de larga distancia.
  • Multimodo: núcleo mayor, común en ciertos enlaces de edificios y centros de datos.
  • Core: núcleo por el que se propaga la luz.
  • Cladding: revestimiento óptico que ayuda a mantener la luz dentro del núcleo.

9. Reflexión, refracción e índice refractivo

La reflexión es el cambio de dirección de la luz al rebotar en una superficie. La refracción es el cambio de dirección al pasar entre medios con distintas propiedades ópticas. El índice de refracción indica cómo se propaga la luz en un medio.

10. Apertura numérica

En fibra óptica multimodo, la apertura numérica expresa la capacidad de la fibra para aceptar luz dentro de determinados ángulos. Depende de los índices de refracción del núcleo y del revestimiento.

11. Canalizaciones y espacios

Las canalizaciones, bandejas y ductos protegen y organizan el cableado. El diseño debe considerar cantidad y diámetro de cables, capacidad de crecimiento, radios de curvatura, accesibilidad y separación de los conductores eléctricos.

12. Administración y rotulación

La identificación de cables, tomas, patcheras y racks facilita el mantenimiento y reduce errores. Las etiquetas deben ser legibles, coherentes y reflejar la documentación de la instalación.

13. Puesta a tierra

La puesta a tierra y la unión equipotencial contribuyen a la seguridad de las personas y los equipos, y ayudan a gestionar determinadas corrientes de falla y perturbaciones eléctricas. Deben diseñarse e instalarse según la normativa correspondiente.

Unidad N.º 2: Características e instalaciones

1. Resistencia de tierra

Es la oposición que presenta el sistema de puesta a tierra al paso de corriente hacia el terreno. Su valor depende, entre otros factores, de las características del suelo, los electrodos y la geometría de la instalación.

2. Jabalina vertical

Es un electrodo que se instala verticalmente en el terreno para formar parte del sistema de puesta a tierra. La cantidad, longitud y disposición se determinan según el diseño y las mediciones.

3. Medición de la puesta a tierra

La resistencia se verifica con instrumentos y métodos apropiados, como los métodos de caída de potencial o equipos específicos compatibles con el sistema instalado.

Los trabajos eléctricos deben ser realizados por personal capacitado y de acuerdo con las normas de seguridad aplicables. No se debe asumir que una instalación es segura sin verificarla.

4. Data Center

Un centro de datos alberga servidores, almacenamiento, redes y sistemas auxiliares que permiten procesar y conservar información. Su diseño contempla disponibilidad, seguridad, refrigeración, energía, cableado y protección contra incidentes.

5. Cuarto de telecomunicaciones

Es un espacio destinado a alojar equipos de comunicaciones, distribuidores de cableado, patcheras y otros componentes. Debe tener espacio de trabajo adecuado, orden, ventilación y acceso controlado.

6. Decibel (dB)

El decibel es una unidad logarítmica que expresa una relación entre magnitudes. En telecomunicaciones se utiliza para representar ganancias, pérdidas y niveles de señal.

  • Ganancia: aumento relativo de una señal.
  • Atenuación: disminución de la señal durante su transmisión.

Para una relación de potencias:

dB = 10 × log₁₀ (P₂ / P₁)

Un resultado positivo representa una ganancia relativa; uno negativo representa una pérdida, según la relación elegida.

7. Mediciones del cableado

  • Mapa de cableado: verifica la correspondencia de los conductores entre extremos.
  • Longitud: mide o estima la longitud del enlace.
  • Tiempo de propagación: tiempo que tarda la señal en recorrer un tramo.
  • Diferencia de retardo: diferencia de propagación entre pares.
  • Atenuación: pérdida de potencia de la señal.
  • Pérdida de retorno: energía reflejada debido a discontinuidades de impedancia.

8. Diafonía y parámetros de desempeño

La diafonía es la interferencia que una señal genera sobre otro par de conductores.

  • NEXT: diafonía medida en el extremo cercano.
  • FEXT: diafonía medida en el extremo lejano.
  • ACR: relación entre la atenuación y la diafonía NEXT, expresada como diferencia de niveles en dB.
  • ELFEXT: FEXT normalizada considerando la atenuación del enlace.

Estos parámetros permiten evaluar la calidad del enlace y comprobar si cumple los requisitos de la categoría de cableado instalada. Las denominaciones y métodos exactos dependen del estándar de certificación aplicable.

Unidad N.º 3: Montaje y control

1. Montaje de equipos

El montaje puede realizarse en un laboratorio o directamente en el lugar de instalación. Debe seguir un diseño previo y respetar las condiciones de seguridad, orden y compatibilidad.

2. Pruebas parciales y totales

  • Pruebas parciales: verifican componentes o tramos individuales.
  • Pruebas totales: comprueban el funcionamiento del sistema completo.

3. Medición y certificación

Un certificador de cableado realiza mediciones para comprobar parámetros eléctricos y determinar si un enlace cumple los requisitos de una categoría o clase determinada. No es lo mismo que una prueba básica de continuidad.

4. Carga inicial de software

Después de montar los equipos, se instala y configura el software necesario. Deben comprobarse las versiones, licencias, recursos disponibles, seguridad y rendimiento.

5. Administración de redes

La administración comprende el monitoreo, la configuración, la gestión de usuarios, el control de permisos, las actualizaciones, el mantenimiento y la documentación de los servicios.

6. Servidores de correo, Web, FTP y bases de datos

Cada servidor cumple una función específica y requiere una configuración acorde con el servicio, las necesidades de los usuarios y las políticas de seguridad.

  • Correo: gestiona el envío y la recepción de mensajes.
  • Web: publica sitios y aplicaciones.
  • FTP: permite transferir archivos.
  • Base de datos: almacena, organiza y permite consultar información.

7. Integración de sistemas

Consiste en hacer que distintos sistemas, aplicaciones y servicios intercambien información de forma coordinada. Requiere compatibilidad, protocolos adecuados, control de acceso y pruebas.

8. Virtualización

La virtualización permite ejecutar máquinas virtuales sobre un equipo físico mediante un hipervisor. Cada máquina virtual puede contar con su propio sistema operativo y recursos asignados.

9. Análisis de costos y presupuestos

Un presupuesto de infraestructura debe considerar materiales, equipos, mano de obra, instalación, configuración, certificación, mantenimiento y posibles costos de actualización.

10. Garantías y documentación

La documentación final debe registrar el diseño, los equipos, las rutas de cableado, las etiquetas, las configuraciones, los resultados de las pruebas y las condiciones de garantía.

11. Prueba piloto y ajustes finales

La prueba piloto consiste en implementar el sistema en una parte controlada del entorno antes de extenderlo. Permite identificar fallas, corregir configuraciones y comprobar que los requisitos se cumplan antes de la implementación definitiva.
